# Airline Booking System

Учебный проект по разработке базы данных системы бронирования авиабилетов с функцией выбора мест на карте самолёта.

## О проекте

Проект представляет собой систему бронирования авиабилетов с реляционной базой данных и веб-интерфейсом для выбора рейсов и мест в самолёте.

## Основные возможности

- Проектирование структуры реляционной базы данных.
- Хранение информации о рейсах, пассажирах, билетах и бронированиях.
- Выбор мест на интерактивной карте самолёта.
- Отображение свободных и занятых мест.
- Создание и обработка бронирований.
- Подготовка данных для аналитики продаж.

## Используемые технологии

- MySQL — система управления базами данных.
- SQL — создание таблиц, запросы, связи и транзакции.
- HTML и JavaScript — веб-интерфейс.
- Python — генерация тестовых данных.

## Структура проекта

- `front` — пользовательский интерфейс.
- `logical` — логическая модель базы данных.
- `rdbms` — материалы по реализации в СУБД.
- `mapping` — материалы проектирования.
- `datatypes` — типы данных.
- `rel` — реляционная модель.
- `businessinfo` — описание предметной области.
- `pm` — материалы проектирования.

## Статус проекта

Учебный проект. Для полноценной работы веб-интерфейса требуется локально запущенная база данных MySQL и соответствующая настройка подключения.
